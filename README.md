# MiLocation для Safari на Mac

Личный автономный форк [GeoSpoof/geospoof](https://github.com/GeoSpoof/geospoof), репозиторий: [Mihaliks/geospoof](https://github.com/Mihaliks/geospoof).

Расширение меняет геолокацию и часовой пояс, которые страницы получают через браузерные API. Системное время Mac и внешний IP оно не меняет.

## Независимость от автора

- Полная база `geo-tz@8.1.6` (геометрия и индекс) включена в приложение. Поиск по координатам работает локально даже при первом запуске.
- Каталог групп сайтов и его указатель включены в пакет. Фоновые обновления не обращаются к CDN GeoSpoof.
- Оригинальные нативные приложения, платёжные серверы, активация и канал автообновления автора не используются.
- Нативная macOS-оболочка сгенерирована инструментом Apple из открытого расширения и изменена для этого форка.
- Собственные название и значок отличают форк от оригинального продукта.

Ручной ввод координат и применение сохранённой настройки не требуют сети. Поиск города обращается к Nominatim/OpenStreetMap. Если включить синхронизацию с VPN, она обращается к сторонним сервисам определения IP/региона. Добавленные пользователем списки сайтов загружаются с указанных им адресов. Это не полностью офлайн-приложение во всех режимах; зависимости от CDN автора нет. Подробности — [политика приватности](PRIVACY_POLICY.md).

## Использование

1. Откройте `/Applications/MiLocation.app` и нажмите «Открыть настройки Safari…».
2. В Safari включите MiLocation и разрешите доступ к нужным сайтам.
3. Через кнопку MiLocation в Safari выберите город или координаты и включите защиту местоположения.
4. Перезагрузите уже открытые страницы.

Для Стамбула: координаты `41.0082, 28.9784`, часовой пояс определяется локально как `Europe/Istanbul`.

## Сборка через Xcode

Нужны macOS 15+, Xcode 27.2+ и Node.js 24.15+. Установите зависимости:

```bash
npm ci --ignore-scripts
```

Откройте `macos/MiLocation/MiLocation.xcodeproj`. Для целей приложения и расширения выберите свою Team в Signing & Capabilities. Затем:

```bash
./scripts/build-safari-macos.sh
```

Результат: `build/macos/Build/Products/Release/MiLocation.app`. Скрипт собирает веб-ресурсы, проверяет локальные данные и отсутствие адресов автора в исполняемых ресурсах, затем собирает и проверяет подпись приложения.

Проверки:

```bash
npm run type-check
npm run lint
npm test -- --maxWorkers=4
npm run test:safari
npm run build:safari
node scripts/check-standalone.mjs
```

Некоторые upstream-тесты сами пересобирают `dist/` для других браузеров. Поэтому после тестов перед упаковкой снова выполняется `npm run build:safari`.

## Установка и подпись

Приложение хранится в `/Applications/MiLocation.app`. Данные расширения остаются в хранилище Safari; приложение-оболочку можно закрыть. Подписанный пакет не требует включать «Allow unsigned extensions» при каждом запуске Safari.

Сертификат установленной 10 ноября 2026 года локальной сборки Apple Development действует до 10 ноября 2027 года. Перед его истечением потребуется обновить сертификат и пересобрать приложение. Обещания бессрочной подписи нет; автоматическое переподписание не настраивалось.

## Ограничения Safari

При проверке установленной сборки после полного перезапуска Safari обычные вызовы API показали `Europe/Istanbul`, UTC+3 и координаты Стамбула. Но первый синхронный скрипт в HTML успел получить системный `Europe/Berlin` до применения настройки. Значит, раннее чтение часового пояса может раскрыть системное значение; полную защиту от этого форк не обеспечивает.

Сохраняются ограничения исходного механизма подмены браузерных API: в частности, покрытие URL/service workers и изменения HTTP-заголовков зависит от возможностей Safari. Расширение не скрывает принадлежность IP VPN-провайдеру и не гарантирует нераспознаваемость подмены.

Проверено 10 ноября 2026 года: 5443 основных теста и 31 тест Safari прошли; проверка типов, ESLint (одно существующее предупреждение в upstream-тесте), сборка Xcode, проверка подписи и аудит упакованных ресурсов выполнены. Разрешения сохранились после перезапуска Safari. Временное правило Стамбула для `127.0.0.1` удалено; общая синхронизация с VPN сохранена.
