# Приватность MiLocation

Эта страница описывает форк Mihaliks/geospoof для Safari на macOS. Исходная политика автора сохранена в `PRIVACY_POLICY.upstream.md` и не описывает изменения этого форка.

## Локальные данные

Настройки, выбранные координаты, часовой пояс, избранное и правила сайтов хранятся в локальном хранилище расширения Safari. Нативная оболочка не передаёт их автору и не использует его App Group, покупки или сервер активации. Сервер аналитики/телеметрии в форке отсутствует.

Полная географическая база часовых поясов, каталог групп сайтов и языковые каталоги включены в пакет. Их чтение использует адреса ресурсов самого расширения; запросов к `cdn.geospoof.com` или другим адресам GeoSpoof для работы не требуется.

## Необязательные сетевые функции

- Поиск города и обратное геокодирование: `nominatim.openstreetmap.org`. Сервис получает запрос или координаты и сетевой IP обращения.
- Синхронизация с VPN: сервисы `get.geojs.io`, `free.freeipapi.com`, `reallyfreegeoip.org`, `ipinfo.io` определяют геолокацию внешнего IP. Проверка изменения IP использует `checkip.amazonaws.com`, `www.cloudflare.com/cdn-cgi/trace`, `whatismyip.akamai.com`, `api.ipify.org`. Сервис видит IP, с которого поступает запрос.
- Списки сайтов по ссылке: расширение загружает адрес, добавленный самим пользователем; его сервер видит этот запрос и внешний IP.
- Ссылки «Помощь» и «Проверить защиту» открывают соответственно этот форк на GitHub и BrowserLeaks только по нажатию пользователя.

Ручной ввод координат и подмена по сохранённой настройке работают без этих сервисов. Проверка реальных городов в тестах запрещает любые внешние сетевые обращения.

## Доступ к сайтам

Для подмены API расширению нужен доступ к соответствующим страницам. Область разрешения контролируется настройками Safari. Настройки Allowlist/Denylist внутри расширения дополнительно управляют применением подмены; они не заменяют разрешения браузера.

Для удаления используйте Safari → Настройки → Расширения, затем удалите приложение MiLocation. Управление данными расширения выполняется средствами Safari.
